### 目标

在已有搜索、原文读取、引用扩展和方法判断能力上，减少科研问题的不确定性与核查负担：发现不同解释和路线，定位关键证据，比较研究差异，形成有条件、可回访的理解或选择。不能把现状描述成“只会搜索”，也不以接口数、来源数或报告长度衡量进步。

先判断卡点：找不到、读不到、无法比较、判断表达不准确，再对应改善发现、读取、概念/条件对齐、判断与依据的对应。证据比较与适用性是优先探索方向，不锁死首项；领域探索和数据/代码/材料复用也在范围内，由真实任务决定先后。

### 轻量 ontology：必要的概念区别

| 概念 | 含义与边界 |
|---|---|
| 科研问题 | 想弄清什么以及使用情境；允许探索，不强迫先有待证明的结论。 |
| 研究资源 | 论文、补充材料、数据、代码、方案、量表文件等来源；保留必要身份与版本。 |
| 研究或分析活动 | 资源描述的研究、设计或分析；论文不等于独立研究，共享样本的分析不自动算独立证据。理论/概念文献不强制填此项。 |
| 证据项 | 与问题有关、可定位到原文方法/结果/表图等的具体信息及关键条件。 |
| 判断 | 我们根据证据形成的解释、比较或建议，说明适用范围和不确定性。 |

必要关系只有三类：资源间的版本/补充/派生关系；证据的来源位置及必要研究归属；判断受到证据的支持、限制或质疑。最后一类属于解释，不冒充接口返回的客观事实。作者相同或标题相似不能直接合并研究；关系不明就保留未知。

样本、构念、方法、测量工具和条件通常随任务描述，当它们成为比较对象时可以提升为独立概念。五类不是封闭清单，不要求知识图谱、统一字段或永久主张库。读过全文、核过数值、运行代码、成功复现分别表达，不能互相替代。

### 行为 spec

输入复用对话已有问题、用途和约束，缺少关键条件才补问。先形成可修正的问题地图与不同路线，再深读影响判断的材料；已有聚焦问题可直接比较，不必每次重走领域全景。

输出先说当前理解或建议，再给必要比较、依据、适用条件及未知，详略随任务调整。决定性主张应读到真正支持它的材料并给可回访位置；摘要和搜索片段只支持其实际承载的信息。重要更正/撤稿信息按判断影响核查，未发现通知不等于证明有效。

反例服务于可能改变判断的条件，不强凑反对论文；研究差异可能来自条件、测量或设计，不先判定矛盾。未搜到不等于不存在或已证明研究空白。不默认承诺穷尽、系统综述、元分析、统计重分析或计算复现。

停止条件：证据与问题重要性相称，主要替代解释已考虑，未知及访问限制清楚，进一步检索没有明确预期收益。关键缺口仍可能改变判断时，说明暂不能判断及最小补证方向。科学上无定论可以是合格结果。

### 验收、防漂移与开放选择

以真实需要的科研任务检验，先用现有能力；不制造测试题、固定论文数或强制多轮实验。验收看六件事：问题是否推进；重要维度/路线是否遗漏；关键判断是否有真正支持的出处；研究/资源/版本是否误并或重复计数；适用条件是否具体；减少的错误和核查负担是否值得新增步骤。

捏造来源、错误合并、把未运行称为复现必须纠正；不为满分无限返修。一次回答正确不等于新增功能有效，未做对照不宣称能力提升或普遍优势。

复用顺序：现有能力、具有独有价值的成熟工具、薄适配、必要自建。重复缺口或一次高影响缺口均可构成评估理由，不要求同一错误反复发生。PaperQA2、OpenScholar、COSMIN、OpenAlex、ASReview 等保留为候选线索，本轮未逐项核实其现状/学科适用性，也未部署。Zotero/Obsidian 分工仅为协作设想，不表示已接通或获得写入授权。

本轮核对了两项基础原则：[Cochrane 区分研究与多份报告](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05)，[DataCite 区分资源关系](https://datacite-metadata-schema.readthedocs.io/en/4.7/appendices/appendix-1/relationType/)。只借鉴必要区别，不搬入完整综述或元数据治理流程。

暂定目标、概念区别、证据边界与验收；首个真实任务、技术架构、工具组合、存储字段和自动化方式保持开放。后续规划可挑战这些起点，但须解释如何更好满足目标及验收，不能被降格为执行既定工具清单。
