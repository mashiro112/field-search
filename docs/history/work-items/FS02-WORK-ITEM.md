## 目标与建项轮边界

在现有搜索、原文阅读、引用扩展、方法判断能力上，减少科研问题的不确定性与核查负担。先识别瓶颈是找不到、读不到、无法比较，还是判断不准确，再决定需要什么增量。

本工作项承接研究方向的规划、规格与最小下一步。本轮只创建和登记，不启动长调研、工具安装、批量部署、自动化或 Execution/Critic；不修改 FS01 的 canonical、合同、Skill 或运行目录，不重新读取旧聊天或重做深度调研。

## 轻量概念与证据边界

| 概念 | 必要含义 |
|---|---|
| 科研问题 | 想弄清的问题、用途和情境；允许探索。 |
| 研究资源 | 论文、补充材料、数据、代码、方案等，保留必要身份与版本。 |
| 研究/分析活动 | 资源描述的研究、设计或分析。论文不等于研究，共享样本的分析不自动算独立证据；理论文献不硬填研究活动。 |
| 证据项 | 与问题有关、能定位到原文位置的信息及关键条件。 |
| 判断 | 据证据形成的解释、比较或建议，保留适用范围和不确定性。 |

重要关系为资源间的版本/补充/派生、证据出处与必要研究归属，以及判断受到证据的支持/限制/质疑。支持关系属于解释，不能冒充接口返回的客观事实。作者相同或标题相似不足以合并研究；关系不明保留未知。按问题需要描述样本、构念、方法、测量和条件，不要求完整知识图谱或统一永久存储。

复用已有问题与约束，只补问影响正确性的缺口。围绕可能改变判断的路线和材料推进；关键判断对应真正支持它的原文位置。搜索片段或摘要仅支持其实际承载的信息；读到全文、核过数值、运行代码与成功复现分别表达。未搜到不等于不存在，研究差异不预设为矛盾；重要未知与访问限制需要明确。

## 验收判据

验收关注问题是否推进、重要路线是否覆盖、关键判断是否有真实出处、研究与版本是否误并或重复计数、适用条件是否具体，以及收益是否值得新增核查步骤与负担。以真实科研问题检验，先看现有能力表现，不预设论文数或固定实验轮数。

科学上无定论可以合格；关键缺口仍可能改变判断时，交代最小补证方向。捏造来源、错误合并和把未运行称为复现必须纠正。单次回答正确不等于功能提升；没有相应比较证据，不宣称普遍优势。证据与问题重要性相称、主要替代路线已考虑、未知清楚且继续检索无明确预期收益时可以停止。

PaperQA2、OpenScholar、COSMIN、OpenAlex、ASReview 仅为候选线索，未验证、未部署。Zotero/Obsidian 未接通且无写入授权。
