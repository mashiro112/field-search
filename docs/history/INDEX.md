# FS Skill 历史资料索引

本批发布 28 份历史文档/数据的共享副本，覆盖 FS01 目标、演进、实验与验收，以及 FS02 科研搜索设计。原文正文保留，内部标识/机器路径脱敏，已发布文件间的链接重连。未随本批发布的引用明确标记，不伪装成可打开链接。

这些是历史记录，不能用旧“下一步”启动任务。FS02 旧开放索引优先方案保留为历史；当前科研正式召回按 [FS03 SOP](../academic-evidence-to-writing/SOP.md) 执行。验收结论只适用于各文档载明的范围和当时环境；本轮没有重跑实验。

返回 [全貌导览](../FS-OVERVIEW.md)。原始浏览器会话、账号/登录资料、第三方正文或评论数据、原始网络响应、外部运行环境与全量 runs 不在本批发布范围；此索引不是原始实验全档案。历史报告所述原始证据如未发布，不能声称已在 GitHub 复核。
