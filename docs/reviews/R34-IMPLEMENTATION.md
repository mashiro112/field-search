日期：2026-10-04。状态：接入与限定验收已完成；本页保留原验收约定，实际结果和失败边界见 [R34-RESULTS.md](R34-RESULTS.md)。

用户已选择 R33 全部 13 个分支。目标是让 FS 根据实际问题调用这些能力，拿回可查证、可复用的材料。复用现有连接器、官方接口和成熟组件；只补必要的薄接入。无需新研究平台、默认后台监控或付费 API。

## 验收约定

1. **论文全文与附件。** 用 DOI 或题名找到确定的论文身份和可读的公开全文；已声明的附件单独列出来源。至少两篇真实论文，包含全文不可用或附件未知的反例。不能把摘要当全文，也不能把链接存在当下载成功。

2. **引用扩展。** 从确定的种子论文取回参考文献和引用它的论文，标明方向、来源、返回数量与限制。至少两篇种子；查不到或额度受限时明确报出，不把空结果说成没有引用。

3. **数据与代码。** 从论文及 DataCite 等明确关系发现关联材料，保留 DOI/URL、关系、版本和可见许可。至少两个真实资源，能够打开相关说明；不凭关键词相似就声称属于同一研究。

4. **引用核查。** 核对报告里的论文身份、版本及元数据声明的更正/撤稿，再定位决定性原文。实测身份不匹配与原文无法访问的情况。元数据核查不代替事实审查，也不自动给论文打可信度分。

5. **项目设计讨论。** 读 PR 描述、评审、行内评论、文件变更，以及 Discussion 的问题和回复。至少一个含行内评审的真实 PR 和一个 Discussion；保存原链接，明确分页及可见范围。

6. **更多社区。** 实际搜索并读回新增社区的帖子和回复。至少两个独立样本，包含登录/访问失败的情况。已有 HN 或普通网页入口不算新增；有登录门槛时保留直接可用的公开路线。

7. **跨材料查找。** 在用户明确指定的网页、报告、Feed、社区帖子和字幕集合内搜索，返回原句及来源位置。真实混合材料、损坏文件与重复内容均测试。不扫描全盘，不丢掉材料类型。

8. **换个说法也能找。** 使用小型本地语义组件，实测中文换词、跨语言、精确标识符和无相关答案。与文字搜索比较真实命中与成本；不把近似字面匹配包装成语义搜索，排序也不等于证据支持。

9. **跨视频查找。** 在至少两份已有字幕内搜同一问题，返回视频身份、原字幕与可点击时间点。字幕缺失或来源不一致要报出。默认复用字幕，不下载音视频或重做转写。

10. **扫描件和复杂页面。** 增加真正可调用的 OCR/页面路线，保留页码、图片和文字位置。至少两种真实页面，与图片核对关键数字、中文及表格位置。识别质量不足时供定位和回看，不宣称表格/公式已经准确重建。

11. **ChatGPT 研究报告归档。** 取回已完成报告，保留正文、表格和引用对应关系，接入本地 report 的分页/查找/复用。先用现成任务验证，不重新生成研究。登录或宿主接口不足时报告具体缺口；完整性无法验证则仍是部分可用。

12. **解释一次变化。** 比较两次已保存材料，指出实质新增/删除，区别已标明的导航噪音与提取失败，并保留两份原始快照。至少一个真实正文变化及两个反例。只是一次检查，不自动创建监控。

13. **专项来源。** 数据集、专利、法规各保留可实际调用的入口和原文读取，标明资源身份、发布/生效信息及适用范围。每类真实样本通过；检索索引、专利状态提示或行政发布不能直接代替许可/权利/法律结论。需要账号的官方接口不偷偷换成付费服务。

## 实现顺序和成本边界

科研、项目/社区、材料查找三条线并行；报告取回、OCR 与专项来源共用已有读取和缓存后段。基础脚本用标准库，较重组件留在独立可选运行环境。每次在线探测限制结果和时间，先用小样本确认价值；已经获得的正文直接保存，不让模型复述全文。

公开仓库只记录源码、设计、可共享的验证摘要与失败条件。报告正文、会话、账号数据及机器路径保留在本地。最终状态逐项写明已接入、已实测、仍需人工或未通过；旧版本验收不冒充这次测试。
