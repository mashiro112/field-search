# R35：已登录 Edge 的 Bluesky 网页搜索与回复读取

日期：2026-10-04。用户已登录 Edge，授权继续完成 Bluesky 接入；Linux.do 已明确不需要。

目标是让 FS 能复用现有登录，直接搜帖子、读原帖及讨论、保留可追溯链接。验收要求：真实搜索有正文及来源；线程核对请求原帖后再返回上下文；隐藏旧页面不混入结果；限量、空结果和失败不冒充完整覆盖；本地保存全文、只输出短摘要；保留用户原标签页。无需再次登录或付费 API。

## 采用的路径

复用已安装的 [OpenCLI](https://github.com/jackwener/opencli) 1.8.7（Apache-2.0）及已有 Browser Bridge；页面浏览器标识含 `Edg/`，确认连接到 Edge。OpenCLI 自带 Bluesky `search` 查的是用户，不能当作帖子搜索。FS 新增标准库薄适配，通过已有 `context community-search/thread bluesky --browser-profile` 入口调用网页操作、读取当前显示的 DOM。原有匿名 API 路径保持独立；此前的 403 没有改称成功。

每轮使用独立的 owned session 并释放自己的 tab lease；OpenCLI 可复用它管理的页面。没有绑定、导航或关闭用户原标签页，没有读取 Cookies 或私人账号存储，没有发帖、关注或点赞。单步最多 30 秒，工作预算 87 秒，留出至 90 秒的清理预算。默认不滚动；搜索可显式增加最多 3 次滚动，不建立全站采集器。

## 真实验收结果

通过 FS 正式入口搜 `Docling`，热门与最新各保留 3 条正文、作者、显示日期及帖子 URL。热门包含 Tim Kellogg、Simon Willison 和 Eric Deandrea 的帖子，最新样本显示 2026-10-02 至 10-03 的内容；两种排序确实不同。最终最新排序加一次滚动返回 5 条、URL 无重复。成功调用实测约 6–10 秒，属于这些本机样例的耗时，不是通用速度保证。

读取 [Simon Willison 的原帖](https://bsky.app/profile/simon.fedi.simonwillison.net.ap.brid.gy/post/3l7zjl2gnzfq2)，保留原文及其博客链接，再保存两条 Lukas Bergstrom 的回复。搜索中的该帖与线程原帖正文一致。线程默认参数可直接工作；上下文可能包含祖先或回复，未核对的关系保持未知，不能宣称完整回复树。

保存的搜索快照已接上既有 `materials find`：离线查找 `MIT licensed` 返回原帖 URL 及对应片段，不需要重新访问网页。

不存在匹配的随机查询返回 0 条且 `empty=true`；先核对网页实际“找不到符合……的结果”提示，没有把空加载页面当成零结果。多个 `searchScreen` 会留在 DOM 中，适配排除隐藏、零尺寸的旧屏幕。所有成功结果仍标为 `partial`、`complete=false`，表示已取回有限样本。

实际验收发现并修复了 Windows GBK 输出 emoji 失败、头像被误读成作者/时间、`#` 翻译链接干扰原帖识别，以及浏览器线程默认数量超过上限。取消了不必要的 helper 子进程，避免外层提前终止清理。空状态按真实页面文字补齐；排序通过实际标签控件选择，而不是构造未经验证的 URL 参数。

10 项离线回归通过：严格来源 URL、超时与 Bridge 失败、输出覆盖保护、跨来源参数隔离、不支持的分页、旧 API 保留、两种线程默认值及原帖不匹配时释放 lease。Skill 验证通过。真实页面验收与离线故障检查分别记录，不把模拟失败当作本机退出登录的验证。

## 使用与边界

[使用说明](../../references/r35-bluesky-web.md)含实际命令、上限和会话要求。搜索返回最多 10 帖；线程返回原帖及最多 10 条上下文。当前标签与 DOM 结构变化、登录失效或 Bridge 未连接会使该可选路线不可用。没有证明全平台覆盖，也没有测出固定 token 节约比例。

完整快照只保留在任务本地；公开仓库仅同步源码、说明和验收摘要，不同步会话、账号信息或原始登录页面。Linux.do 的旧代码与历史失败记录保留，已从当前待推进事项移除。
