# R34：13 条分支的接入结果

日期：2026-10-04。按 [验收约定](R34-IMPLEMENTATION.md)完成接入与限定验收。
以下是本轮真实运行结果与反例，不把历史试验、代码存在或 API 元数据当作原文验证。
新路线已通过统一 `search.py` 入口安装；参数见 [R34 使用说明](../../references/r34-routes.md)。

## 现在可以用什么

1. **论文身份与公开全文。** `scholarly resolve` 通过 Crossref/OpenAlex/Europe PMC 找论文及公开原文入口。正常已配置的 `read` 路由保存了 AZD1222（PMC8522798，47,771 字符、9 页）和 RECOVERY tocilizumab（PMC8084355，67,832 字符、14 页）的完整提取响应；离线方法检索与末页对照通过。论文中 32,451 人、2:1 分配，以及低氧/CRP 纳入条件和药物剂量均可定位。全文提取仍保留第三方抽取警告。Science 原始出版社页面实测返回访问验证，明确 unavailable；不能用摘要替代。附件未声明时返回 unknown，不声称已经获取全部附件。

2. **引用扩展。** 两个真实种子 DOI 的 OpenAlex 参考方向及引用方向取回成功；CRISPR 种子有 159 个参考 ID，返回量遵守 limit。输出保留样本、来源、数量与覆盖限制，不能把引用它等同于支持它，不递归扩展整张图。

3. **关联数据/代码。** DataCite 精确 DOI 关系与 Dataset/Software 类型筛选通过。两个可读原始说明的真实正例为 Dryad `10.5061/dryad.684v0` 和 `10.5061/dryad.qn514810`，均登记版本 1、CC0、IsCitedBy。前者有样本与文件用途，[后者原始说明](https://datadryad.org/dataset/doi:10.5061/dryad.qn514810)明确列出实验数据及关联 Python/Perl 模拟代码。另一个 TIB `10.82209/rpd7-x122` 的身份、版本 1、CC BY 4.0、IsDerivedFrom 可读取，但原站网页不可访问且登记 description 为空，保留为受限反例。广义关键词命中但仅有参考关系的记录不冒充研究附件。代码型筛选已接入，但本轮并未下载/运行代码或数据文件。

4. **引用身份与更正信息。** 真 DOI 搭配错误题名返回 mismatched/partial；不存在 DOI、HTTP 200 但结构错误等情况保留失败/未知。保留 Crossref update/relation 与 Europe PMC 可见状态；它们不能证明“没有撤稿”或判断结论正确。决定性原文通过后段查找，出版社访问门槛为真实反例；没有自动论文可信度分数。

5. **项目设计讨论。** VS Code #339301、CPython #158584 两项真实 PR 包含 reviews、行内评审、对话评论、文件变更和 patch。GitHub Discussion #1 取回 45 个可见正文块；完整回复覆盖未知，原始 HTML 供复查。集合限制、分页与 patch 截断分开表达。

6. **新增公开社区。** Lemmy.World 搜索、两个独立帖子及评论分页可实际使用，保留帖子/评论身份、正文、父回复与原链接。两项帖分别报告 343/191 条评论，限定返回量明确 partial；第二页实测没有冒充全部回复。Discourse 搜索连接已有主题读取器。Linux.do 返回 AUTH_REQUIRED，Bluesky 在当前环境返回 403；这两条未计为成功新来源，公开路线仍可用。

7. **混合材料查找。** 同一明确清单含真实网页、报告、Feed、社区和两份视频字幕；字面查找返回原句、URL、哈希和位置。另一个集合、重复/损坏文件、无效 UTF-8 和 Unicode casefold 扩展均检查。失败文件不会让整批假成功，也不会自动扫描全盘。报告文字层样本属于本地夹具，真实其他来源分别标明。

8. **中文换词与跨语言。** 直接使用 FastEmbed 0.7.3/ONNX CPU 与多语 MiniLM（当前 mean pooling），未部署 QMD/向量服务。混合集合 326 条记录拆为 439 块；中文换词、英文改写都找到同一段 B 站字幕（0.75365/0.48269）；无关问题低于所选门槛。PEP 810 语义误排保留为反例，字面检索可正确定位。长文尾部的受控测试命中 14,800–15,054 字符；超过 1,000 块标 partial。空模型目录返回 unavailable，禁止检索时自动下载模型。

9. **跨视频定位。** 在已有 YouTube/Bilibili 字幕中返回视频身份、原字幕、起止时间与跳转 URL。中文/英文改写指向 B 站 94.36 秒；字面搜索分别找到 YouTube 43 秒与 B 站 8.339 秒等原段。未下载媒体、重做 ASR 或读取浏览器凭据。

10. **页面 OCR 与回看。** 直接调用 RapidOCR 3.9.2 的本地 CPU 模型，保留原页 PNG、页码、框坐标与置信度。现代中文页面、Attention 表格/公式页，以及专利权利要求/更正页实测。中文局部区域正确找回罚款数字；整页双栏顺序可交错，区域选择缓解这一点。历史竖排中文、指数和复杂表格仍识别失准，能力验收限定为定位与原图核对。哈希损坏拒收，已保存结果无运行时也可复用。

11. **ChatGPT 研究报告完整归档。** 未重新发起研究；在已有完成报告中捕获正文及可见来源面板，通过只绑定 127.0.0.1、一次保存后退出的表单接收器落盘。18 个正文标题、4 张表/147 个单元格、76 处引用/15 个来源索引与实际结尾核对通过；离线分页/find、真实正文损坏及回执校验通过。保留原始 HTML 与哈希。一个生成报告中的 URL 本来含可疑编码与省略号，原样保留并警告，不宣称已验证来源内容。官方导出/Copy、OpenCLI 获取结果仍失败，新验收来自不同的原生 DOM 路线。

12. **一次变化比较。** 两个已公开的项目背景版本（`23d818f` → `56e0dce`）真实正文变化被识别，两份原文保留；导航夹具、自比较、提取失败和损坏快照分别检查。比较保留科学指数、不等式与 Markdown 自动链接差异，避免兼容性归一化吞掉含义。它输出变化线索与限制，不默认建订阅或后台监控。

13. **数据集、专利与法规。** 数据集复用第 3 项；两个真实专利通过原始 PDF/已有转换与页面 OCR 读取。US8697359B1 的扫描权利要求页与两张更正页原先未进入普通文本转换，OCR 后可定位并看图；原图里的历史更正不等于当前权利状态。Google Patents 自动查询提示曾被旧快照当正文，本轮已在抓取和缓存读取两处修复拒收。US Federal Register 实际读回一项 Rule 和一项 Notice，保留文件号、原文、官方 govinfo PDF、发布日期/生效日及适用地区；中国官方《个人信息保护法》全文及第七十四条也可离线定位。未自动推断法律效力或数据许可结论。

## 怎样复用成熟方案

直接接入：FastEmbed、RapidOCR/ONNX/PyMuPDF；继续复用 MarkItDown、文档/报告分页、已保存字幕、现有 Discourse/OpenCLI。
API 接入：Crossref、OpenAlex、Europe PMC、DataCite、GitHub REST、Lemmy、Federal Register。
FS 自己新增的是显式路由、预算/失败状态、材料和结构适配、哈希复用及本地文件交接。
没有另造科研平台、抓取器框架或默认生成式模型服务。出处与许可见 [集成地图](../../references/integration-map.md)及使用说明。

## 成本、验证和剩余边界

基础入口为标准库；OCR/语义依赖隔离。第一轮多语模型获取约 235 MB，后续本地检索禁止下载；本机混合集合查询约 8 秒，OCR 现代中文页约 6 秒，依材料变化，不能推成通用性能保证。
浏览器正文直接变量交给本地表单，未在模型工具输出里回显整篇研究报告。在线 API 有请求/字节/结果限制，保存原记录后输出短摘要。调研实现与复查分派给低用量工作模型；未测量总 token 节约比例，不作百分比承诺。

统一入口实测、本机运行配置、语法/Skill 校验、关键失败反例与独立只读审查完成；审查中发现并修复了 argv 分发、长文语义截断/字符串位置字段、损坏快照降级读取、报告正文/回执复用校验等问题。临时 pagination shim 属诊断记录，已撤出正常全文验收依据。
私有报告、账号数据、会话和机器路径不随本页或源码发布。本轮没有人工节点阻挡公开可用路线；Linux.do 等访问限制仅影响对应可选来源。
