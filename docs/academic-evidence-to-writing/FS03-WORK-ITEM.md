## 目标与默认关系

将用户选定的科研搜索到写作流程固定为**当前科研场景唯一默认 SOP**：[SOP.md](SOP.md)。现有 field-search 组件、FS01/FS02 记录与成果保留，可作为新流程内的辅助能力；旧方案不再作为本场景并列默认入口。此默认关系是文档规格，尚未修改 installed Skill 或接通自动路由。

核心链路：研究问题 → Codex 检索式 → PsycINFO + Scopus + WoS（教育主题按需 ERIC）→ Elicit Pro 合并/去重/筛选 → 引用与长尾补漏并回筛 → Zotero 原文库 → Elicit Evidence Matrix → Codex 大纲与 Claim–Evidence Map → Paragraph Evidence Packet → 写作 → 原文、逻辑与结论强度审核。

## 本轮范围与证据边界

交付中文 SOP 和[最小模板](templates.md)，核对链接、JSON 和内容一致性。来源为来源任务已读取的 ChatGPT 对话“学习模式与普通Chat区别”最新回复与紧邻背景摘要；本轮不重复读取、不独立核实产品能力，不固化“200篇”等上限。

不启动真实检索、安装、自动化、其他角色或学术账号外部写入；不修改 FS01、FS02、现有 field-search 或 installed Skill。原 Skill 源码快照已在本仓库单独发布；本次追加科研工作流文档。未来修改共享 Skill 前须明确唯一写入者、目标和写入窗口；FS03 Home 身份不自动授予共享写权。
