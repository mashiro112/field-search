## 使用原则

搜到论文、提取证据、建立论证、写正文分别完成。每个决定性判断均可追到实际读到的原文位置；摘要只能支持摘要实际载明的内容。访问失败、全文未读或归属不明分别记明，不能补成已核实。

普通定向查询按具体问题限制范围，可合并记录、按需补漏，停止于足以支持限定判断且关键缺口已说明。系统综述应预先写明纳排标准、完整检索与筛选记录、适用的质量/偏倚评价方法及复核安排，并报告各阶段数量与缺失。两者共用以下链路，不把小查询强制升级为完整综述，也不以执行流程承诺检索穷尽。

study 是研究活动，report 是报告该活动的论文/资源，version 是该报告的预印本、发表版或修订版。一篇 report 可含多个 study，一个 study 可对应多篇 report；共享样本的不同分析也可能相关。保留关联依据与未知状态，不能只按标题/作者自动合并；去除重复记录不等于删除同研究的不同报告。汇总证据以独立研究/样本为依据，不按报告数或版本数叠加支持强度。

## 工具与访问边界

正式召回默认 PsycINFO + Scopus + WoS；教育主题按需 ERIC。默认非医学研究，不自动加入 PubMed 或临床库。OpenAlex/Semantic Scholar 只作为后台元数据、邻近文献或引用辅助，不能替代正式召回。Scholar GPT/Sider 可选，无必要增购，不因可选工具缺席阻断已可进行的步骤。

Elicit 等工具在这里是用户选定的负责节点，并非本轮验证过的产品功能清单。实施时先核对官方当前能力、导入/导出格式、订阅与独立 API 权限/配额；不固化单次篇数上限，不将网页订阅视为 API 授权。导出文件可由用户手动交接，格式以实际支持为准。

缺访问时交付“停在阶段 N、已有产物位置、缺少什么、谁需做哪一步、恢复条件”，继续不依赖该访问的准备工作。正式库不可访问时保留检索式等待用户临时打开网页；不能静默改用开放索引并声称完成正式召回。若只获得部分库结果，明确部分覆盖。产品能力核查、人工交接和实际执行分别记状态。
