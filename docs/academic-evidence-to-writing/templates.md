# 科研证据到写作：最小模板

配套 [SOP](SOP.md) v1.0。以下均为空模板，不是执行记录。每个真实任务复制一份，定向查询可用短行/条目填写；系统综述保留完整记录与计数。空白不能表示零、通过或已完成，未知写“待核”。

## 0 任务与交接卡

- 任务 ID / 日期 / 负责方：
- 研究问题、用途与目标产物：
- 严格度：定向查询 / 系统综述；选择理由：
- 人群、概念、情境、时间/语言/研究设计范围及理由：
- 纳入标准 / 排除标准：
- 综述适用的质量或偏倚评价方法、筛选/提取复核安排（定向查询可简化）：
- 当前阶段与实际访问状态（账号自述 / 已验证网页 / 已执行 / 未连接分开）：
- 已有产物路径 / 阻塞项 / 负责方 / 恢复条件 / 最小下一步：
- 结束范围、停止理由及未解缺口：

## 1 检索记录

每次检索一行；完整检索式过长时存文件并填写精确路径。正式召回与补漏分开标记。

| 检索 ID | 类型（正式/引用/长尾/元数据） | 数据库与实际平台/渠道 | 完整检索式或文件；补漏种子与方向 | 字段、限制及理由 | 执行者与日期 | 访问/执行状态 | 命中数与实际导出数 | 批次路径/格式 | 缺口/备注 |
|---|---|---|---|---|---|---|---|---|---|
| 待填 | | | | | | 未执行 | 待核 | | |

Gemini 建议的候选与实际 Google Scholar 检索分别记录；未操作的库不填已搜。保存原始批次，后续去重不抹掉来源。

## 2 筛选、排除与身份对照

record ID 标记召回记录；report ID 标记报告；version ID 标记版本；study ID 标记研究，可多对多或暂为未知。重复记录映射到保留记录；不同报告/版本保留身份关系，不能以去重丢弃独有信息。

| record ID / 来源批次 | report ID / DOI或稳定标识 / 标题 | version ID / 版本关系 | study ID / 样本关联组 | 身份关系依据或待核 | 去重决定 / 保留 record ID | 筛选阶段（题摘/全文/补漏回筛） | 决定（纳入/排除/待审/待全文） | 排除理由或待办 | 审核者 / 日期 / 复核分歧处理 | 原文/Zotero位置 |
|---|---|---|---|---|---|---|---|---|---|---|
| 待填 | | | | | | | 待审 | | | |

系统综述追加计数：原始记录 __；重复记录 __；题摘筛选 __；题摘排除 __；寻求全文 __；未获取全文 __；全文评估 __；全文排除及各理由数量 __；纳入 reports __；独立 studies __；新增补漏批次 __。核对流向，不把未获取全文自动归为不符合纳入条件，不把 report 数写成 study 数。

## 3 Evidence Matrix

每行一个可定位证据项；同一研究多条证据共用 study ID，合成判断时只计相应独立研究/样本，不按行数投票。理论或方法文献可写 study 不适用，不伪造样本。

| evidence ID | study / report / version ID | 设计、样本与情境 | 构念/测量、比较及分析 | 结果与关键数值（单位/不确定性） | 原文摘录或忠实释义 + 页/节/表/图/段定位 | 适用条件、局限/质量评价 | 证据角色（支持/限制/反证/背景） | 提取者 / 原文核对者 / 日期 / 状态 | 相关样本组与不重复计证说明 |
|---|---|---|---|---|---|---|---|---|---|
| 待填 | | | | | | | | 待核 | |

仅有摘要须明确标记，决定性提取不能冒充全文核对。PDF 位置应记录文档页码或阅读器页码的口径。

## 4 大纲与 Claim–Evidence Map

- 大纲与各节目的：

| claim ID / 所属节 | 观点句 | evidence ID 与原文定位 | 支持/限制/反证关系与理由 | 独立研究/相关样本归组 | 适用范围与允许结论强度 | 缺口及处理（补证/收窄/删减） | 审核状态 |
|---|---|---|---|---|---|---|---|
| 待填 | | | | | | | 待审 |

## 5 Paragraph Evidence Packet

每段复制以下卡片。写作模型只使用已通过的版本；不得把“待审”解释为默认通过。

- packet ID / 版本 / 对应段落与 claim ID：
- 段落目的与上下文衔接：
- 核心观点句：
- 使用文献：report/version ID、引用标识、evidence ID、原文文件/Zotero位置及页/节/表/段：
- 各证据角色及组织顺序（支持、限制、反证或背景）：
- study/样本关联及计证说明：
- 关键数值、必要方法事实与适用条件：
- 允许得出的结论与强度：
- 尚不支持的扩展、待核信息：
- 写作要求（语言、风格、篇幅）：
- 审核者 / 日期 / 状态（待审、返修、通过）及问题处理：
- 正文交付位置 / 引用核对、逻辑核对、结论强度核对结果：

写作发现证据不足时，返回矩阵与证据包补齐或收窄观点；最终审核逐项追踪关键句，不用“整体看起来合理”替代原文核对。
